Type9 v0.2 — умные подсказки и автообновление.

**Новое**
- Большой встроенный словарь: 150 000 русских и 100 000 английских слов + модель контекста (пары и тройки слов).
- Подсказки учитывают предыдущие слова и согласование падежей: «о этом мес…» → «месте», «с колл…» → «коллегами», «по этому воп…» → «вопросу».
- Режим «Подсказывать после пробела» — следующее слово по смыслу ещё до первой буквы («добрый ␣» → «день»).
- Выбор языка подсказок (по умолчанию русский): при русском английские слова не предлагаются.
- Автообновление из GitHub Releases с проверкой SHA-256; словарь, фразы и настройки сохраняются.
- Расширенный набор деловых фраз (приветствия, благодарность, ответы, просьбы, извинения, завершение) и сокращений; кнопка «Стандартные фразы».
- Лиловый акцентный цвет вместо рубинового.

**Исправлено**
- Мерцание кругового меню при прокрутке колеса: страницы плавно сменяют друг друга.
- Наведение мыши на подсказку больше не сбивает выбранный для Tab вариант.
- Плавность анимаций на 60 Гц; предкомпиляция (ReadyToRun) и прогрев — первая подсказка без задержки.
- Сторож хуков ввода: если Windows сняла хук, он переустанавливается автоматически.

**Скачать**
- `Type9.exe` — один файл, ничего устанавливать не нужно (облегчённая версия больше не выпускается).

Версия 0.1 не умеет обновляться сама — замените exe вручную один раз; дальше обновления придут автоматически.
