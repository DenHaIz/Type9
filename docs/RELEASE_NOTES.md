Первая публичная версия Type9.

**Что внутри**
- Автодополнение в любом текстовом поле Windows: `Tab` — вставить, `↑/↓` — выбор, `Esc` — скрыть.
- Обучение на вашем тексте и предсказание следующего слова; «Обучить на тексте» в настройках.
- Круговое меню фраз по удержанию `Alt+Q` (группы, цифры 1–8, боковые кнопки мыши).
- Сокращения с подстановками `{date}`, `{time}`, `{clipboard}`.
- Тёмная/светлая/системная тема, акцентные цвета, RU/EN интерфейс, авто-масштаб под экран.
- Обычный режим и режим администратора, автозапуск.

**Какой файл скачать**
- `Type9-lite.exe` (~0,6 МБ) — если установлен .NET Desktop Runtime 10.
- `Type9.exe` (~150 МБ) — самодостаточный, ничего устанавливать не нужно.
