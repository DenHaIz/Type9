# Type9 — handoff

Состояние на **v0.1.0** (17.11.2026). Документ для того, кто продолжит разработку.

## Что это

Резидентная программа для Windows (трей): глобальное автодополнение в любом поле ввода + круговое меню фраз по
горячей клавише. C# / .NET 10 / WPF, без сторонних NuGet-пакетов в приложении. Сборка — один `.exe`.

## Структура

## Ключевые решения

- **Хуки на отдельном потоке.** Windows молча снимает LL-хук, если колбэк долго не отвечает; UI-поток может быть занят.
  Принятие подсказки (SendInput) выполняется прямо в колбэке — так сохраняется порядок с последующими нажатиями.
- **Свои вводы не обрабатываются**: `dwExtraInfo == Win32.InjectionMarker`. Чужие инжектированные события (RDP, AutoHotkey) обрабатываются.
- **Устаревшие подсказки**: каждое изменение контекста увеличивает `InputEngine.Version`; UI применяет подсказки только для текущей версии,
  Tab принимает только актуальный снимок.
- **Вставка фразы из меню** ждёт отпускания модификаторов (иначе Alt+символы), длинные фразы (>200) — через буфер обмена с восстановлением.
- **Alt в хоткее**: после срабатывания шлётся «пустая» клавиша VK 0xE8, чтобы отпускание Alt не открывало меню окна.
- **Темы**: WPF замораживает Freezable в ресурсах приложения, поэтому кисти не анимируются, а заменяются; плавность —
  кросс-фейдом снимка окна (`SettingsWindow.CaptureForCrossfade`). Сектора колеса имеют свои кисти и анимируются напрямую.
- **Масштаб**: `UiScale` (0 = авто по рабочей области в DIP) → LayoutTransform корня окон; окно настроек ограничено 92% экрана.
- **Single-file без сжатия** для self-contained: со сжатием ~67 МБ файл, но ~125 МБ RAM; без — ~150 МБ файл и ~20 МБ RAM.
- **Логотип и иконка** генерируются кодом (`LogoRenderer`); `Resources/type9.ico` пересоздаётся `Type9.exe --export-icon <путь>`.

## Служебные ключи

| Ключ | Назначение |
|---|---|
| `--autostart` | запуск из автозагрузки: без окна настроек |
| `--restart` | перезапуск (после смены режима), ждёт освобождения мьютекса |
| `--no-elevate` | не поднимать права, даже если в настройках режим администратора |
| `--export-icon <путь.ico>` | сгенерировать иконку и PNG логотипа |
| `--snapshot <папка>` | отрисовать все окна (темы × языки × масштабы) в PNG |
| env `TYPE9_DATA_DIR` | другая папка данных (тесты, портативный режим) |

## Проверено

- `dotnet test` — 30/30.
- Вёрстка всех разделов настроек, колеса и плашки: тёмная/светлая тема, RU/EN, масштаб 100% и 130% (через `--snapshot`).
- Запуск exe-файлов: lite ≈ 19 МБ RAM, self-contained (без сжатия) ≈ 21 МБ RAM в простое; словари грузятся, лог без ошибок.

## Не проверено вживую (сделать первым делом)

Сборка и разработка шли в сессии без доступа к рабочему столу, поэтому **глобальный ввод не прогонялся руками**:
1. Подсказки в Блокноте, Chrome/Edge (адресная строка и textarea), Telegram, Word/Outlook; RU/EN раскладки, CapsLock.
2. Tab вставляет, ↑/↓ выбирают, без подсказки Tab работает как обычно; умная пунктуация.
3. Круговое меню: удержание Alt+Q, отпускание, цифры, колесо мыши, Esc; Alt не открывает меню окна; боковые кнопки мыши.
4. Позиционирование у каретки на 100%/150% DPI и двух мониторах.
5. Режим администратора: UAC при переключении, задача Планировщика, работа в окне «от администратора».

## Идеи на следующие версии

- Большие частотные словари (например, hermitdave/FrequencyWords, CC-BY-SA 4.0) — положить в `%AppData%\Type9\dict` или встроить.
- Вложенные страницы колеса и перетаскивание фраз мышью в редакторе.
- Персональные подсказки по приложению (контекст: процесс).
- Портативный режим (данные рядом с exe).
- Подписание exe (SmartScreen ругается на неподписанные файлы).
