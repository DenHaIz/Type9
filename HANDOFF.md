# Type9 — handoff

Состояние на **v0.3.1** (17.11.2026). Документ для того, кто продолжит разработку.
Репозиторий: https://github.com/DenHaIz/Type9 · автор коммитов: `denhaiz`.

## Что это

Резидентная программа для Windows (трей): глобальное автодополнение в любом поле ввода (как T9) + круговое меню
готовых фраз по горячей клавише (как buy-menu CS:GO / chat wheel Dota 2). C# / .NET 10 / WPF, без сторонних
NuGet-пакетов в приложении. Выпускается **один самодостаточный `Type9.exe`** (облегчённая framework-dependent версия
убрана по решению владельца).

**Приоритеты владельца:** стабильность и скорость > потребление памяти > размер exe. Интерфейс — RU/EN, тёмная/светлая
тема, бордовый акцент по умолчанию, плавные анимации на каждое действие (рассчитаны на 60 Гц).

## Как выпустить версию

1. Поднять `<Version>` в `src/Type9/Type9.csproj` (формат `0.X.Y`; тег — `v0.X` или `v0.X.Y` для исправлений).
2. Переписать `docs/RELEASE_NOTES.md` (без BOM — он становится текстом релиза).
3. `dotnet test Type9.sln` и `.\build\build.ps1` локально.
4. Коммит от `denhaiz <denhaiz@users.noreply.github.com>`, без строк соавторства; `git tag -a v0.X -m "Type9 v0.X"`;
   `git push origin main` и `git push origin v0.X`.
5. Workflow сам соберёт exe, посчитает SHA-256 и создаст релиз. Установленные копии обновятся в течение 6 ч
   (или сразу по кнопке «Проверить сейчас»).

## Языковая модель

Пересборка (нужны скачанные данные, в репозиторий не кладутся):

```powershell
# ru_full.txt / en_full.txt — github.com/hermitdave/FrequencyWords (content/2018/<lang>/<lang>_full.txt)
# rus_sentences.tsv / eng_sentences.tsv — downloads.tatoeba.org/exports/per_language/<lang>/<lang>_sentences.tsv.bz2 (распаковать)
dotnet run -c Release --project tools/DictBuilder -- --lang ru --freq ru_full.txt --sentences rus_sentences.tsv `
    --extra tools/DictBuilder/business_ru.txt --vocab 150000 --min2 2 --min3 2 --out src/Type9/Resources/Dict/ru.t9lm
dotnet run -c Release --project tools/DictBuilder -- --lang en --freq en_full.txt --sentences eng_sentences.tsv `
    --extra tools/DictBuilder/business_en.txt --vocab 100000 --min2 2 --min3 3 --out src/Type9/Resources/Dict/en.t9lm
```

- RU: 150 000 слов, ~414 тыс. биграмм, ~482 тыс. триграмм, ~83 тыс. пар окончаний; EN: 100 000 / 489 тыс. / 462 тыс.
- Имена, которыми переполнен Tatoeba («Том», «Мэри»…), исключаются только в заглавной форме — «о том» остаётся.
- **Модель окончаний**: P(2 последние буквы следующего слова | 3 последние буквы предыдущего) / P(окончания) — даёт
  согласование падежей без морфологического словаря («этом» → «-те», «с» → «-ами»).
- В памяти загружаются только модели выбранного языка подсказок. Лицензии: FrequencyWords — CC BY-SA 4.0, Tatoeba — CC BY 2.0 FR.

## Обучение на тексте пользователя

- Слово попадает в очередь при завершении (пробел/знак), а **фиксируется**, когда начато следующее слово
  (`CommitDistance` = 3 символа), после паузы 1,5 с (`AppController._learnIdleTimer`) или при уходе из поля/клике.
- Backspace в ещё не зафиксированное слово, Ctrl+Backspace, Ctrl+Z, ←, Home, Delete — это правка: очередь выбрасывается.
- Не учится: поля паролей (Win32 `ES_PASSWORD` сразу; браузеры/Electron — через UIA при каждой смене фокуса,
  до проверки очередь не фиксируется), программы-исключения, адреса/почта/пути (`CompletedWord.Learnable`), смесь алфавитов.
- В подсказках незнакомое модели слово появляется со второго употребления; пользовательский контекст сглажен (+2).
- `UserModel.Prune`: при > 150 тыс. слов удаляются разовые слова старше 60 дней.
- Словарь не сохраняется, пока не загружен (слова, выученные во время загрузки, сливаются); при ошибке чтения файл
  копируется в `.broken`, сохранение отключается до перезапуска.

## Подсказки: клавиши и запятая

- `Tab` вставляет выбранный вариант сразу по нажатию. Пока Tab зажат, цифра 1–9 (и на цифровом блоке) **заменяет**
  вставку вариантом N (`InputEngine.ReplaceAccepted`: стирает вставку, возвращает стёртые буквы, печатает другой вариант);
  автоповтор Tab после вставки поглощается. Любая другая клавиша или отпускание Tab завершают режим.
- Колесо мыши над плашкой листает варианты (дельта копится до 120 — тачпад не пролистывает всё сразу); страница под
  плашкой при этом не прокручивается. `↑/↓` по-прежнему работают.
- **Запятая после приветствия** (`Greeting.NeedsComma`, настройка `GreetingComma`): «здравствуйте/привет/приветствую/hello/hi»
  в начале предложения и пары «добрый день/вечер», «доброе утро», «good morning…» (допускается «всем» перед ними).
  Запятая есть и в дополнении слова, и в подсказке следующего слова. Если сразу после вставки набрать `,` `.` `!` `?` `:` `;`,
  наша запятая (и авто-пробел) заменяются этим знаком: «Здравствуйте!» (`InputEngine._autoComma`).

## Горячие клавиши меню

- Обычное сочетание (Alt+Q и т.п.) поглощается; после Alt/Win шлётся «пустая» клавиша VK 0xE8 (не открывается меню окна/Пуск).
- **Одиночный модификатор** (`Hotkey.IsSingleModifier`: RCtrl, RAlt, LWin…) не поглощается: меню открывается через 140 мс,
  только если клавиша всё ещё зажата одна (`InputEngine._otherKeyDuringHold`, `AppController.OnRadialOpen(delayed)`);
  в режиме «нажатие» — по отпусканию «чистого» нажатия. RCtrl+C и т.п. работают как обычно.
- F-клавиши, CapsLock (тогда не переключает регистр), кнопки мыши — хоткеи без модификаторов; буквы без Ctrl/Alt запрещены.
- `HotkeyBox` записывает модификатор по его отпусканию; `HotkeyAdvisor` показывает предупреждение о конфликте.

## Круговое меню на экране

- `RadialMenuWindow.Place`: монитор под курсором, его DPI (`GetDpiForMonitor`), окно ставится на место ещё скрытым
  (WPF заранее получает DPI — без «прыжка»), целиком в рабочей области (за край уходит только поле тени).
- Перед открытием ждём каретку до 90 мс; если меню перекрыло бы строку — ставим выше/ниже (где ближе и помещается).
- Если меню сдвинуто относительно курсора, курсор переносится в центр и возвращается после закрытия.
- Подсветка выбора: цвет сразу на 75% и 70 мс до конца, текст без анимации. Сектор **не выдвигается** (с 0.3.1): при
  быстром ведении мыши по кругу движение отставало от курсора. Смена страниц — перекрёстная анимация двух слоёв с BitmapCache.
- Стандартный набор — 3 группы по 8 фраз (Приветствия, Ответы, Завершение); `PhraseBook.CurrentDefaultsVersion = 4`,
  нетронутые наборы v0.1–v0.3 (`LegacyPhraseTexts` + `V3PhraseTexts`) заменяются при запуске.

## Ключевые решения

- **Хуки на отдельном потоке** + сторож: раз в минуту простоя хуки переустанавливаются (Windows молча снимает LL-хук
  при таймауте). Принятие подсказки (SendInput) — прямо в колбэке, чтобы сохранить порядок нажатий.
- **Свои вводы не обрабатываются** (`dwExtraInfo == InjectionMarker`); чужие инжектированные (RDP, AutoHotkey) — обрабатываются.
- **Версии контекста**: подсказки применяются и принимаются только для актуального `InputEngine.Version`.
- **Наведение мыши на плашку не меняет выбор для Tab.**
- **Скорость**: ReadyToRun, прогрев после загрузки модели, GC `SustainedLowLatency`, фоновая сборка, рабочий набор
  не урезается. Подсказка ≈ 6 мс в худшем случае (префикс из 1 буквы).
- **Темы**: кисти в ресурсах приложения WPF замораживает → заменяются; плавность — кросс-фейд снимка окна настроек.
- **Чёткость при масштабе** (`UiScale.PixelAlign`): масштаб интерфейса — LayoutTransform на самом внешнем элементе окна,
  а окну через `VisualTreeHelper.SetRootDpi` сообщается DPI × масштаб. Тогда WPF округляет раскладку и растеризует текст
  сразу под реальные пиксели (иначе при 90/115/130% и масштабе Windows 125/150% рамки «плывут», текст мылится).
  Следствие: `VisualTreeHelper.GetDpi` в этих окнах возвращает DPI × масштаб — для физических пикселей экрана
  использовать `UiScale.DeviceScale`. Кеши `BitmapCache` (тень плашки, диск колеса) получают `RenderAtScale` = этот DPI.
  Шрифт — Segoe UI (вариативный Segoe UI Variable WPF рисует хуже), минимальный размер текста 11,5–12.
- **Вставка фраз**: ждём отпускания модификаторов; длинные (> 200 символов) — через буфер обмена с сохранением всех
  форматов; если буфер занят — печатаем.
- **Автообновление**: через 20 с после старта и раз в 6 ч; без SHA-256 и без права записи в папку exe — не ставится;
  exe переименовывается в `.old`, новый запускается с `--restart --updated <версия>`; данные в %AppData% не трогаются.
- **Single-file без сжатия**: со сжатием сборки распаковываются в память (+~80 МБ RAM).

## Известные риски

- **Доверие к обновлениям = доверие к GitHub-аккаунту.** SHA256SUMS.txt лежит в том же релизе, что и exe: это защита
  целостности, а не подлинности. Следующий шаг — подпись exe (Authenticode) или подписанный манифест с открытым ключом,
  зашитым в программу (закрытый ключ — в секретах GitHub Actions).
- **Режим администратора** при exe в пользовательской папке: задача Планировщика с наивысшими правами указывает на файл,
  который может подменить любая программа пользователя. В настройках показывается совет перенести exe в Program Files.
- Отката, если новая версия не запускается, нет (`.old` удаляется при старте новой версии).

## Служебные ключи

| Ключ | Назначение |
|---|---|
| `--autostart` | запуск из автозагрузки: без окна настроек |
| `--restart` | перезапуск, ждёт освобождения мьютекса |
| `--updated <версия>` | запуск после автообновления: уведомление в трее |
| `--no-elevate` | не поднимать права, даже если в настройках режим администратора |
| `--export-icon <путь.ico>` | сгенерировать иконку и PNG логотипа |
| `--snapshot <папка>` | отрисовать все окна (темы × языки × масштабы, с прокруткой «Общих») в PNG |
| env `TYPE9_DATA_DIR` | другая папка данных (тесты, портативный режим) |

## Не проверено вживую (сделать первым делом)

Разработка шла в сессии без доступа к рабочему столу, поэтому **глобальный ввод руками не прогонялся**:
1. Подсказки в Блокноте, Chrome/Edge, Telegram, Word/Outlook; RU/EN раскладки; режим «после пробела»; поля паролей в браузере;
   Tab+цифра (замена вставки в разных редакторах), колесо мыши над плашкой, «Здравствуйте,» + «!».

3. Режим администратора: UAC, задача Планировщика, работа в окне «от администратора».
4. Чёткость на мониторах 125/150% и при переносе окна настроек между мониторами с разным DPI (`PixelAlign` + `DpiChanged`).

## Идеи

- Подписание exe и подписанный манифест обновлений.
- Морфологический словарь (OpenCorpora) для точного согласования; персональные подсказки по приложению.
- Перетаскивание фраз мышью в редакторе; вложенные страницы колеса.
- Откат обновления, если новая версия не стартовала за N секунд.
