# Type9 — handoff

Состояние на **v0.3.0** (17.11.2026). Документ для того, кто продолжит разработку.

## Что нового в 0.3 (кратко)

- **Одиночная клавиша для меню**: `Hotkey.IsSingleModifier` (RCtrl/RAlt/LWin…) — модификатор не поглощается, меню открывается
  с задержкой 140 мс только если клавиша зажата одна (`InputEngine._otherKeyDuringHold`, `AppController.OnRadialOpen(delayed)`);
  в режиме «нажатие» — по отпусканию «чистого» нажатия. F-клавиши, CapsLock, кнопки мыши — обычные хоткеи без модификаторов.
  `HotkeyBox` записывает модификатор по отпусканию. `HotkeyAdvisor` — предупреждения о конфликтах (Ctrl+C, F5, Mouse4…).
- **Позиционирование колеса** (`RadialMenuWindow.Place`): монитор под курсором, DPI через `GetDpiForMonitor`, окно ставится
  скрытым до показа; не перекрывает строку каретки (ждём `CaretLocator` до 90 мс); при сдвиге курсор переносится в центр и
  возвращается после закрытия. Выбор сектора — от центра колеса.
- **Обучение**: отложенная фиксация слов (`InputEngine._pending`): слово фиксируется, когда начато следующее
  (`CommitDistance` = 3 символа после слова), после паузы 1,5 с (`AppController._learnIdleTimer` → `CommitPendingLearning`)
  или при смене поля; Backspace в ещё не зафиксированное слово — отмена,
  `CompletedWord.Learnable` (адреса/почта/смешанные алфавиты), незнакомое словарю слово предлагается при count ≥ 2,
  сглаживание +2 в знаменателях пользовательского контекста, `UserModel.Prune` (> 150 тыс. слов → удаляются разовые старше 60 дней).
- **Фразы**: новый RU-набор (без латиницы/смайлов/«(а)»), `PhraseBook.Version` и миграция нетронутых наборов прошлых версий
  (`IsUntouchedLegacyDefaults` по текстам из v0.1/v0.2).
- **Анимация выбора в колесе**: цвет сразу на 75% и 70 мс до конца, текст без анимации, выдвижение 110 мс.

## Что это

Резидентная программа для Windows (трей): глобальное автодополнение в любом поле ввода + круговое меню фраз по
горячей клавише. C# / .NET 10 / WPF, без сторонних NuGet-пакетов в приложении. Выпускается **один самодостаточный
`Type9.exe`** (облегчённая framework-dependent версия убрана по решению владельца).

**Приоритеты владельца:** стабильность и скорость > потребление памяти > размер exe.

## Языковая модель

Пересборка (нужны скачанные данные, в репозиторий не кладутся):

```powershell
# ru_full.txt / en_full.txt — github.com/hermitdave/FrequencyWords (content/2018/<lang>/<lang>_full.txt)
# rus_sentences.tsv / eng_sentences.tsv — downloads.tatoeba.org/exports/per_language/<lang>/<lang>_sentences.tsv.bz2 (распаковать)
dotnet run -c Release --project tools/DictBuilder -- --lang ru --freq ru_full.txt --sentences rus_sentences.tsv `
    --extra tools/DictBuilder/business_ru.txt --vocab 150000 --min2 2 --min3 2 --out src/Type9/Resources/Dict/ru.t9lm
dotnet run -c Release --project tools/DictBuilder -- --lang en --freq en_full.txt --sentences eng_sentences.tsv `
    --extra tools/DictBuilder/business_en.txt --vocab 100000 --min2 2 --min3 3 --out src/Type9/Resources/Dict/en.t9lm
```

- RU: 150 000 слов, ~414 тыс. биграмм, ~482 тыс. триграмм, ~83 тыс. пар окончаний; EN: 100 000 / 489 тыс. / 462 тыс.
- Имена, которыми переполнен Tatoeba («Том», «Мэри»…), исключаются только в заглавной форме — «о том» остаётся.
- **Модель окончаний**: P(2 последние буквы следующего слова | 3 последние буквы предыдущего) / P(окончания) — даёт
  согласование падежей без морфологического словаря («этом» → «-те», «с» → «-ами»).
- В памяти загружаются только модели выбранного языка подсказок.

## Ключевые решения

- **Хуки на отдельном потоке** + сторож: раз в минуту простоя хуки переустанавливаются (Windows молча снимает LL-хук
  при таймауте). Принятие подсказки (SendInput) — прямо в колбэке, чтобы сохранить порядок нажатий.
- **Свои вводы не обрабатываются** (`dwExtraInfo == InjectionMarker`); чужие инжектированные (RDP, AutoHotkey) — обрабатываются.
- **Версии контекста**: подсказки применяются и принимаются только для актуального `InputEngine.Version`.
- **Наведение мыши на плашку не меняет выбор для Tab** (раньше UI и Tab расходились).
- **Скорость**: ReadyToRun, прогрев предсказаний после загрузки модели, GC `SustainedLowLatency`, фоновая сборка,
  рабочий набор не урезается принудительно. Подсказка ≈ 6 мс в худшем случае (префикс из 1 буквы).
- **Плавность**: смена страниц колеса — перекрёстная анимация двух слоёв с BitmapCache; тени кешируются; окно меню
  позиционируется до показа. Длительности анимаций 110/170/250 мс.
- **Темы**: кисти в ресурсах приложения WPF замораживает → заменяются; плавность — кросс-фейд снимка окна настроек.
- **Автообновление**: проверка через 20 с после старта и раз в 6 ч; exe переименовывается в `.old` (это разрешено для
  запущенного файла), новый запускается с `--restart --updated <версия>`, `.old` удаляется при старте. Данные в %AppData% не трогаются.
- **Single-file без сжатия**: со сжатием сборки распаковываются в память (+~80 МБ RAM).

## Аудит 0.3 — исправлено

- Пароли в браузерах/Electron больше не попадают в словарь: обучение не фиксируется, пока поле не проверено через UIA
  (`InputEngine._fieldVerified`, `AppController.OnFocusChanged`); в поле пароля отложенное выбрасывается.
- Словарь не затирается пустым при неудачной/незавершённой загрузке (`_dictLoaded`, `_dictSaveBlocked`, слияние ранних слов).
- Гонка «меню осталось открытым» при быстром отпускании в режиме удержания.
- Вставка через буфер обмена сохраняет все форматы; если буфер занят — фраза печатается.
- Обновление без SHA-256 не ставится; не пытается обновиться, если папка exe недоступна для записи.
- Автоповтор клавиши паузы, повторное нажатие хоткея в режиме «нажатие», автоповтор CapsLock.
- Ctrl+Backspace / Ctrl+Z / ← / Home / Delete после слова — правка, такое слово не учится.
- Запись файлов: блокировка, уникальный временный файл, сброс на диск; при ошибке `Dirty` восстанавливается.
- Импорт словаря и загрузчик модели проверяют данные; утечка подписки превью колеса на смену темы.

## Известные риски (не исправлено)

- **Доверие к обновлениям = доверие к GitHub-аккаунту.** SHA256SUMS.txt лежит в том же релизе, что и exe: это защита
  целостности, а не подлинности. Следующий шаг — подпись exe (Authenticode) или подписанный манифест с открытым ключом,
  зашитым в программу (закрытый ключ — в секретах GitHub Actions).
- **Режим администратора** при exe в пользовательской папке: задача Планировщика с наивысшими правами указывает на файл,
  который может подменить любая программа пользователя. В настройках показывается совет перенести exe в Program Files.
- Отката, если новая версия не запускается, нет (`.old` удаляется при старте новой версии).

## Служебные ключи

| Ключ | Назначение |
|---|---|
| `--autostart` | запуск из автозагрузки: без окна настроек |
| `--restart` | перезапуск, ждёт освобождения мьютекса |
| `--updated <версия>` | запуск после автообновления: уведомление в трее |
| `--no-elevate` | не поднимать права, даже если в настройках режим администратора |
| `--export-icon <путь.ico>` | сгенерировать иконку и PNG логотипа |
| `--snapshot <папка>` | отрисовать все окна (темы × языки × масштабы) в PNG |
| env `TYPE9_DATA_DIR` | другая папка данных (тесты, портативный режим) |

## Проверено

- `dotnet test` — 43/43 (включая качество подсказок на реальных моделях и скорость).
- Вёрстка всех разделов настроек, колеса и плашки (`--snapshot`): тёмная/светлая тема, RU/EN, 100% и 130%.
- `Type9.exe` (Release, ReadyToRun): модель «ru» грузится за ~0,5 с, в простое CPU ≈ 0, ~70 МБ приватной памяти.

## Не проверено вживую (сделать первым делом)

Разработка шла в сессии без доступа к рабочему столу, поэтому **глобальный ввод руками не прогонялся**:
1. Подсказки в Блокноте, Chrome/Edge, Telegram, Word/Outlook; RU/EN раскладки; режим «после пробела».
2. Круговое меню: удержание Alt+Q, колесо мыши (плавность смены страниц), цифры, Esc.
3. Автообновление end-to-end — станет проверяемым с выходом v0.3 (v0.1 не умеет обновляться, на v0.2 надо перейти вручную).
4. Режим администратора: UAC, задача Планировщика, работа в окне «от администратора».
